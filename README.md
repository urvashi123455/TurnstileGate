\# Turnstile Gate with Face Recognition



\## Project Overview

This project is a smart access control system using face recognition and embedded systems.



The system detects and recognizes faces using OpenCV and controls a turnstile gate using ESP8266/ESP32.



\## Features

\- Real-time Face Recognition

\- Blink Detection

\- Smart Threshold Decision

\- Servo Motor Gate Control

\- LED \& Buzzer Alerts

\- GUI Interface

\- COM Port Selection

\- Access Logging



\## Technologies Used

\- Python

\- OpenCV

\- Tkinter

\- Streamlit

\- ESP8266 / ESP32

\- Arduino IDE



\## Hardware Components

\- ESP8266 / ESP32

\- Servo Motor

\- Webcam

\- LEDs

\- Passive Buzzer



\## How to Run



Install libraries:



pip install -r requirements.txt



Run GUI:



py gui.py
